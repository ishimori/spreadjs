## 目的

consumer（広島空港 予算管理モック W-04）が「誰が変えたか」を表の上で示せるようにする（要件メモ H3）。
DD-049 で `remote-change`（actorId・origin・前後値）を受け取れるようになったため、SDK 側は**セル単位の印を描く口**だけを決める。

## 背景・課題

- 要件の正本: 広島リポ `doc/DD/DD-005/sdk-requirements.md` H3「セルを最後に変えた人を色またはツールチップで示す（『私が変えたセル』『相手が変えたセル』の区別）」
- 現状（2026-09-12・DD-049 時点）: `columnFormats` は値→書式、`rowBackgrounds` / `columnBackgrounds` は行列単位で、**セル単位の印を runtime に差し替える口が無い**。Presence の枠・名前タグはライブ位置であり、「最後に変えた人」の静的な印ではない
- consumer のつなぎ（DD-005-2）: 自分の変更だけ `cell-commit` から拾って React 側で色付けし、相手の変更はライブの Presence 枠で見せる
- 状態の所有者を増やす判断が要るため、DD-049（イベント系）とは分けた（DD-049 論点 3・昇格ルール「1DDで複数の状態所有者を変更」の回避）

## 検討内容

| # | 論点 | 選択肢 | 推奨と理由（起票時の仮説） |
|---|------|--------|------------------------|
| 1 | 状態の所有者 | (a) view-local（利用側が `remote-change` から作ったセル→印の map を渡す） / (b) 文書状態（セルに最終変更者を持たせる） | **(a)**。(b) は Operation・snapshot 形式・永続化へ波及し A 昇格。consumer は DD-049 のイベントだけで map を作れる |
| 2 | 公開面 | (a) handle `setCellMarks(marks)`（rowId×columnId→色・runtime 差し替え可） / (b) mount オプション（mount 時固定＝既存の書式系と同運用） | **(a)**。変更のたびに更新する性質で、mount 固定だと remount が要る |
| 3 | 描画の形と重なり順 | (a) セル背景色（値ベース書式・行列背景と優先を決める） / (b) セル右上の角マーク（Presence 枠の下） | **(b)**。値ベース書式の背景色と競合せず、既存の塗りの優先順位を変えない |
| 4 | 「誰が」の表示 | (a) SDK がホバーでツールチップ / (b) 利用側が選択セルから別表示 | **(b)**。ホバー UI は H6 セルコメントと同じ機構にまとめる（stage2-backlog §3.7） |
