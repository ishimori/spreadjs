## 目的

一覧の行から詳細を開く・選んだ行の詳細を横に出す、を consumer が作れるように、選択が変わったこととセルのダブルクリックを知らせる。

## 背景・課題

- 現状（alpha.23）は選択が変わったイベントも、選択中のセルを返す API もない。ダブルクリックは、読むだけのセルで編集を止めたときの `edit-blocked`（`input: 'dblclick'`）しか届かない。consumer のモックは link 列（`link-open`）で代用している

## 決定事項

- 2026-11-20（親 DD-070・推奨案で確定）:
  1. イベント `selection-change { activeCell, range }`（両モード）。`activeCell` は選択中のセル（`GridCellRef`・行が無ければ `null`）、`range` は枠を描いている範囲（`GridCellRange`：左上と右下の行 ID・列 ID。1 セルだけのときも 1 × 1 で入る。結合の左上ならその結合全体。ドラッグ中はドラッグの範囲）
  2. 発火は「前に知らせた内容と変わったとき」だけ。描画のループ（rAF）の終わりで 1 フレームに 1 回まで比べる（ドラッグ中は 1 フレームに 1 回・キーや API の連打もまとめて 1 回）。初回のデータの描画の後に、最初の選択を 1 回知らせる。行の並びが変わって同じセルの番号だけが変わったときは出さない（ID で比べる）。編集中・変換中は選択が動かないので出ない
  3. 命令 `GridInstance.selection(): GridSelection`（今の選択。イベントと同じ形。boot 前・destroy 後は両方 `null`）。React の ref handle にも出す
  4. イベント `cell-dblclick { rowId, columnId }`（両モード）。本体のセルのダブルクリックで、SDK の既定の動き（編集の開始・候補欄・カレンダー・読むだけのセルの `edit-blocked`）の**後**に出す。結合範囲は左上のセル。見出し・列の境界（幅の自動調整）・行番号では出さない。SDK の既定の動きは止めない（止めたい列は consumer が `readOnlyColumns` にする）
