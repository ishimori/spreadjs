## 目的

consumer が作る並べ替え・絞り込み・列のまとまりの折りたたみを、見出しで見せられるようにする（▲▼・絞り込みのボタン・開閉の印）。押した場所（見出しの矩形・絞り込みのボタンか）と、2 段の見出しの上の段のクリックを知らせる。

## 背景・課題

- DD-052-5 は「並べ替え中の表示は consumer が自前で描ける」として対象外にした。実際は見出しを Canvas に描き、`columnCaptions` は mount で決まる（React では変えると作り直し）ので、consumer は描けない（親 DD-070 の背景）
- `header-click` は `columnId` だけで、絞り込みの候補欄を見出しの下に出す位置が分からない。2 段の見出しの上の段のクリックは知らせない（DD-064 K4）
- 見出しの描画は `render/src/base-layer.ts` にあり、このファイルはサイズのガードの超過（1,046 行）で増やせない

## 決定事項

- 2026-11-20（親 DD-070・推奨案で確定）:
  1. 列の見出しの印 `GridColumnHeaderMark { sort?: 'asc' | 'desc'; filter?: 'available' | 'active' }`。mount オプション `columnHeaderMarks`（ColumnId → 印・初期値）と命令 `setColumnHeaderMarks(marks)`（丸ごと置き換え・`{}` で全部消す）。view-local・両モード・開き直さない。boot 前に呼んでもよい（最後の 1 回が勝つ）。React は prop `columnHeaderMarks`（値が変わったら同じ instance の setter を呼ぶ＝mergedCells と同じ）
  2. 描き方: 見出しの右端に、右から絞り込みのボタン（`available`＝枠と ▼・`active`＝塗りつぶしと白い ▼）、その左に並べ替えの三角（▲ 昇順・▼ 降順）。見出しの名前は印を除いた幅の中央に置き、収まらなければ省略記号（印は名前に重ねない）
  3. 列のまとまりの印 `GridColumnGroupMark { collapsed: boolean }`。`GridColumnGroup` に任意の `id`（既定は `caption`）を足し、mount オプション `columnGroupMarks`（id → 印）と命令 `setColumnGroupMarks(marks)`。印のあるまとまりは上の段の名前の左に ▾（開いている）／▸（閉じている）を描く。印が無ければ従来どおり
  4. `header-click` に `rect`（見出しのセルの viewport 矩形）と `target`（`'filter'`＝絞り込みのボタンの上・`'caption'`＝それ以外）を足す（既存の `columnId` はそのまま・追加だけ）
  5. 新しいイベント `column-group-click { groupId, caption, columnIds, rect }`（2 段の見出しの上の段のクリック。`rect` はまとまりの上の段の矩形）。折りたたみの切り替えは consumer が行う（SDK は印を描いて知らせるだけ。見せる列を変えるのは DD-070-7）
  6. 印の配置（矩形）は render の純粋関数 1 つで決め、描画と grid の当たり判定の両方で使う（描いた所と押せる所を食い違わせない）
  7. 不正な指定（未知の列・未知の id・値の誤り）は、その項目だけ捨てて診断 warn（`column-header-mark-invalid`）。mount オプションでも fail-fast にしない（行データの `cellBackgrounds` と同じ扱い）
  8. 見出しの描画は `render/src/header-layer.ts`（新規）へ移す（中身は従来どおり・`base-layer.ts` の行数を減らして baseline を下げる）
