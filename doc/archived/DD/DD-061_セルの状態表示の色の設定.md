## 目的

DD-060 で固定にしたセルの状態表示（error/warning）の枠と背景の色を、consumer がテーマに合わせて変えられるようにする。

## 背景・課題

- DD-060 は色を固定にした（決定事項2）。既知の未保証境界に「consumer のテーマに合わせて変える口はない」と残した
- ユーザーが範囲外の対応を指示（2026-10-22）。他の装飾（`columnFormats`・`rowBackgrounds`）は色を consumer が決めており、状態表示だけ固定なのは不揃い

## 決定事項

ユーザー委任（2026-10-22）により推奨案で確定した。

1. **mount オプション `cellStatusColors`**（両モード共通・mount 時に固定）: `{ error?: { frame?: string; background?: string }; warning?: { frame?: string; background?: string } }`。省略した水準・項目は既定色（DD-060 の色）のまま。React は同名 props（値が変われば開き直す＝`rowBackgrounds` と同じ）
2. **不正な設定は mount 時に fail-fast**（`error` phase=config・code=`column-types-invalid`＝`rowBackgrounds`・`columnBackgrounds` と同じ経路）: オブジェクトでない・`error`/`warning` 以外のキー・`frame`/`background` 以外のキー・空や空白だけの色
3. **CSS の色としての妥当性は検査しない**（他の色オプションと同じ）。不正な色は既定色で描く（engineering-patterns #27: 既定色を入れてから上書きする）
4. 枠の太さ・形は変えない（色だけ）

## 受け入れ基準

| # | 基準（操作 → 期待結果） | 検証方法 |
|---|------------------------|---------|
| 1 | `cellStatusColors: { error: { frame: '#0000ff' } }` で error の枠が青、背景は既定の薄赤のまま。warning は既定色のまま | 描画テスト・E2E（画素） |
| 2 | 不正な色（CSS として解釈できない文字列）は既定色で描かれ、直前に描いた色を引き継がない | 描画テスト |

| 4 | 未指定なら DD-060 と同じ描画（既存テストがそのまま通る） | 既存の描画テスト・E2E |
| 5 | React の `cellStatusColors` からそのまま使える。公開 `.d.ts` の差分は追加のみ | typecheck・consumer-strict・公開面 snapshot・React 単体 |
